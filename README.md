# Railway Ticket Reservation System

A modern, responsive static frontend for railway ticket booking with a clean UI and smooth user experience.

## 🚀 Features

- **Train Search**: Search trains by source, destination, and journey date
- **Multiple Classes**: Choose from Sleeper, AC 3-Tier, AC 2-Tier, and AC 1-Tier
- **Multi-Passenger Booking**: Book tickets for up to 6 passengers
- **Progress Tracking**: Visual step-by-step booking process
- **Price Calculator**: Automatic fare calculation based on passengers
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and intuitive user interface

## 💻 Usage Instructions

### Step 1: Search Trains
- Enter source station (e.g., "Mumbai Central")
- Enter destination station (e.g., "New Delhi")
- Select journey date
- Choose class (Sleeper, 3AC, 2AC, 1AC)
- Enter number of passengers (1-6)
- Click "Search Trains"

### Step 2: Select Train
- Browse available trains
- View departure/arrival times and prices
- Click "Select" on your preferred train

### Step 3: Enter Passenger Details
- Fill in details for each passenger:
  - Full Name
  - Age
  - Gender
- Review total fare
- Click "Confirm Booking"

### Step 4: Confirmation
- View your PNR number
- Review booking details
- Download ticket (simulated)
- Book another ticket if needed



## ⚠️ Important Notes

- This is a **static frontend** demonstration
- All data is stored in memory and resets on page refresh
